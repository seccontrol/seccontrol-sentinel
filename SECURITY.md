# Security Policy

## Supported Versions

SecControl Sentinel receives active security updates and vulnerability triage for all release versions.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The SecControl Security Operations Center takes reports of vulnerabilities seriously.

If you believe you have discovered a vulnerability in SecControl Sentinel or want to submit an IoC:
1. **Do not open a public GitHub issue.**
2. Send an encrypted or direct email to **assistenza@seccontrol.it** .
3. Include detailed reproduction steps and affected components.
4. Our SOC analysts will acknowledge your report within 24 hours and provide an estimated remediation timeline.
